# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层（含检修停用状态）和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- **测点停用窗口**：检修停用只抑制窗口内位移、渗流等设备波动报警，不生成异常。
- **分区静默授权**：仅值班长可授权/撤销，越权提交被拒绝并写审计；静默只作用于非安全报警。
- **安全触达不抑制**：水位、降雨读数触达报警值时，无论测点停用或分区静默，都生成重大异常并直接进入应急联动；同测点未关闭异常自动并入，不重复建单。
- **原始读数只追加**：接入与回补读数不可覆盖；回补读数写入即触发该测点失效重算，重算失败保留前一结论、可重试，成功前一律按前一结论处置。
- **判定冻结**：重算产生新版本评估但不改写源评估；关闭异常只记录关闭事实，原判定永久冻结。
- 异常队列、现场复核、证据、复测评估和专业异议并存（安全触达异常走应急流程）。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- **审阅包**：逐条评估说明为何抑制（停用窗口/分区静默）或放行（含安全触达强制应急），汇总停用窗口、静默授权、重算任务与审计（含越权拒绝），可导出JSON。
- 侧栏可切换值班长/监测员/负责人身份，演示角色鉴权与越权拒绝留痕。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```

## 关键业务规则（`src/app/domain/evaluation.ts`）

| 读数情形 | 停用窗口 | 分区静默（值班长授权） | 结果 |
| --- | --- | --- | --- |
| 位移/渗流 超预警或报警 | 在窗口内 | — | 抑制，不生成异常 |
| 水位/降雨 达报警值（安全触达） | 在窗口内 | 静默中 | **仍然放行，生成重大异常并进入应急联动** |
| 水位预警/渗流报警等非安全报警 | 未停用 | 静默中 | 抑制（分区静默） |
| 读数低于预警值 | 任意 | 任意 | 不报警、不生成异常 |
